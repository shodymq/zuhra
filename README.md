# Zuhra Cakes

Статический сайт-витрина для Zuhra Cakes. Проект запускается без установки зависимостей и без сборки.

## Как запустить локально

1. Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <url-репозитория>
cd zuhra
```

2. Запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

3. Откройте сайт в браузере:

```text
http://localhost:8000
```

Также можно открыть файл `index.html` напрямую в браузере, но локальный сервер лучше повторяет поведение сайта после публикации.

## Структура проекта

```text
.
├── index.html
├── styles.css
├── app.js
├── cake photos/
└── logo/
```

## Разработка

- Основная разметка находится в `index.html`.
- Стили находятся в `styles.css`.
- Интерактивность, меню и корзина находятся в `app.js`.
- Изображения тортов лежат в папке `cake photos/`.
- Логотип лежит в папке `logo/`.
